About Me

Technology Works Best When People Do

I'm an Information Technology major with a minor in Human Resource Development at Texas Tech University's Rawls College of Business, graduating in December 2026. That pairing is what I'm focused on. Most technology projects don't fail because the code is wrong but instead they fail because requirements were unclear, stakeholders weren't aligned, or nobody asked the people doing the work what they actually needed.

I grew up in Houston, raised by a single mother, and I'm the first in my family to attend college. That background shapes how I lead, how I ask questions early, how I make sure quieter voices get heard, and why I care about people in my shoes.

Personal Project · 2025–2026

Secret Menu

My role: Solo developer

A custom publishing platform built from scratch for my girlfriend who enjoys writing and wanted somewhere to post poetry, stories, and papers without the templated design and account overhead of an off-the-shelf blogging service.

What I built

  • Five-page site backed by a hosted Postgres database, with posts fetched client-side through Supabase's REST API.
  • Publishing is limited to one account with no public sign-up route — access comes only from an invite issued in Supabase.
  • Row-level security enforces that restriction at the database layer, so reads stay public while writes require record ownership. The rule holds even if someone bypasses the front end entirely.
  • Wrote a custom invite-acceptance page after finding Supabase's default flow authenticates users but never lets them set a password.
  • Automated deploys from GitHub on every push; the whole stack runs on free tiers.

Built with

HTML / CSS / JavaScript Supabase (PostgreSQL + Auth) Netlify GitHub

Outcome

A live platform the writer publishes on today, at zero hosting cost and with no account required for readers.
